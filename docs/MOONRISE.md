# Moonrise — Nexus Reader 0.3.0

Decided 2026-09-20 from the canvas at
https://claude.ai/artifact/5b7YHM5Hu7rRcq2SpenTRq. The app takes The Second
Calling's own palette, faces and phoenix, and points at tscemu.com and the
`TSC` logs instead of PTDex and `multiclass`. This is the record of what was
decided and how the build departed from it.

## Decisions

| | |
|---|---|
| Accent | **Option A** — silver on the accent, red in the chrome only. The site's red `#d0343f` is eleven degrees of hue from `--bad`, and a status colour must never be a decorative choice. |
| Hover cards | **A JSON route on the site** (`/items/tip`, `/spells/tip`), with the search page as the fallback on a site that has not deployed it. |
| The server's name | **Named.** The title bar's sub-line reads "The Second Calling", in Cinzel. 0.2.0 kept that line generic on purpose; 0.3.0 is built for one server and says so. |
| The other schemes | **Kept.** Obelisk moved into its own `[data-theme]` block so a stored `obelisk` keeps its look. |

## As built

**Theme.** The `:root` block of `theme.css` is The Second Calling (id `tsc`; a `tsc-ember` scheme puts the red on the accent for the literal reading): the site's tokens
verbatim, mapped onto the app's existing names (`--gold` is still "accent").
The aurora is coals (`--blood`, `--line-hi`, `--red-lo`). The title bar's
bottom edge is the site's travelling red filament, eleven seconds end to end.
`code` moved from the secondary to the accent, because in this scheme the
secondary is red and `/log on` should not read as an error.

**Faces.** Cinzel stays; IBM Plex Sans (one variable file) and IBM Plex Mono
(400 and 500) are vendored under `src/shared/theme/fonts/` with the Plex OFL.
Manrope's files are gone. ~105 KB net.

**Mark.** The ring is gone; the mark is the server's phoenix. The program
icon is rendered by `scripts/make-icon.mjs` from `build/phoenix-mark.png`
(the site's `artwork/phoenix-mark`) on a navy plate, screen-blended so the
fire keeps its own colour, with a tighter head-and-shoulders crop for the 16
and 24 entries. The title bar and the first-run hero draw
`assets/phoenix-crest.png`, the site's vignetted crest. `Crest.tsx` and the
`--mark-*` tokens were removed.

**Page headers.** Every section page's banner was rebuilt in the site's
masthead language: its cold-valley ground plate (`assets/ground-cold.jpg`)
under a scrim, the corner brackets its panels wear, a mono kicker in the fire
colour, a Cinzel title with the diamond-and-hairline rule, a silver figure on
the right, and the red filament at the foot. No starfield. One block in
`app.css` ("Page headers") covers `.loot-hero`, `.lb-hero`, `.prog-hero` and
`.page-head`.

**Art.** The Overview banner is the site's `moonrise/banner.jpg`; the
first-run hero carries the phoenix crest low and right. Both ship with the app.

**Server.** Defaults: `https://tscemu.com`, shortname `TSC`. A stored value
that equals the OLD default is moved forward on load (`settings.ts`); a value
somebody typed is left alone. The site is read by `src/main/site.ts` through
pure parsers in `src/main/siteparse.ts`, tested against fixtures cut from the
live site (`tests/fixtures/tsc/`).

- **Identity** — `GET /characters?q=` → `a.chrow`. `Identity.id` is now the
  name in the URL (a string); identities cached with a numeric id are dropped
  on load and looked up afresh. Class spellings are folded by `abbrevOf`.
- **Progression** — the four doors and five tiers, regenerated by a rewritten
  `export-progression.mjs`. Each step carries a `kind` (kill / hail / event)
  and a `mob` (the corpse's name where it differs from the title). A mark from
  the log is drawn as *killed · flag unconfirmed*; a site sync or a manual tick
  makes it *flagged*. The sync also reports gate kills the site holds that the
  account is not flagged for. Marks whose keys name a step that no longer
  exists are pruned once on load.
- **Leaderboards** — `/leaderboards/raids` monuments, drawn as the site draws
  them: marks down, party sizes across, sealed cards for unclaimed encounters.
- **Hover cards** — the JSON routes, then the search page. The cache is keyed
  on the site as well as the name, and entries from before that are dropped.
- **Souls online** — `/world`, once a minute, beside the character picker.
  Shown only when the site says it is counting.
- **Tonight** — a fifth Server tab from `/champions`: the podium, the
  thirty-day feed and the chronicle of firsts.

**Tests.** 27 new in `tests/site.test.ts`; the watcher and history fixtures
now write `_TSC.txt`. On the site, `tests/test_tip.py` (11) and a
`search_spells` fake.

## Not done, and why

- **The Server page's broadcast readers** (blessings, census, auction) were
  written against Project Triune's log lines and are unverified against a TSC
  log. `node scripts/unparsed.mjs` on a real TSC log is the next step; the
  README and TESTING.md both say so.
- ~~**The shortname `TSC` is inferred**~~ — **confirmed 2026-09-20 19:36**.
  It was read off the client's `<Char>_TSC.ini` files because no log existed
  yet; Deezel has since run `/log on` and the client wrote
  `eqlog_Deezel_TSC.txt`, which is what `settings.ts` scans for and what
  `watcher.ts` matches. The default is right.
- ~~**Step 10 of the rebrand, the GitHub rename**~~ — **done 2026-09-20, and
  not as a rename.** `Aoezpz/Triune-Helper` had been **deleted**, so there was
  no name to rename and no redirect to inherit: every URL in this project
  pointed at a 404, including the update feed compiled into 0.1.x. The app now
  publishes to and checks **`Aoezpz/Nexus-Reader`** (`src/shared/update.ts`,
  `electron-builder.yml`, `docs/index.html`). `appId` stays
  `com.projecttriune.helper` — see the note in `electron-builder.yml`; it is
  now the only upgrade path an old install has.
- ~~**The site's endpoint is written and tested, not deployed.**~~ — **live
  2026-09-21 01:01 UTC.** `/items/tip`, `/spells/tip` and `/discs/tip` all
  answer on tscemu.com, and the payloads were checked field by field against
  `tipFromJson`: the pair shapes, `cast_ms`/`recast_ms` dividing to seconds,
  `duration_ticks: 0` becoming null rather than "0 ticks", and the site's
  `CLR` folding through `SITE_CODES` to the app's `Clr`. The search-page
  fallback stays in place for any site that lacks the route.
